# My Website – HTML/CSS Personal Website

## Overview

This project is a **personal website built with HTML and CSS**, originally created as part of a **university assignment**.

It was designed as a simple personal webpage to present basic information, structure content into sections, and practice core front-end development concepts such as layout, styling, and page organization.

This project later served as the **base version** for a ReactJS rebuild, where I recreated the same concept using a component-based approach.

## Purpose

The main purpose of this project was to:

- Practice **HTML and CSS fundamentals**
- Build a structured personal website from scratch
- Improve understanding of **layout and styling**
- Create a base project that could later evolve into a more advanced front-end version
